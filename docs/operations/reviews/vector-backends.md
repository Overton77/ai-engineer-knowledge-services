Normal path: adapter search (`InMemoryExactCosineBackend.search` / `PostgresVectorSearchBackend.search`) → candidates; publish → inspect → verify → transactional insert + pointer advance + event; rollback → verify predecessor → transactional pointer switch + event; reconcile → pointer/publication lookup → inspect → classified findings.

Failure path (`VectorBackendError` codes): `INVALID_DIMENSIONS`, `INVALID_EMBEDDING`, `INVALID_LIMIT` (shared validators); `IMMUTABLE_ITEM_CONFLICT`, `ZERO_VECTOR` (exact backend); `POSTGRES_RPC_FAILED` (or the RPC's own code), `INVALID_RPC_RESPONSE` (Postgres backend); `AUTHORITY_CLASS_VIOLATION`, `INVALID_ITEM_COUNT`, `INVALID_PUBLICATION`, `PUBLICATION_VERIFICATION_FAILED`, `IDEMPOTENCY_CONFLICT`, `DUPLICATE_PUBLICATION`, `DUPLICATE_EVENT` (publish); `INVALID_ROLLBACK`, `INVALID_ROLLBACK_TARGET`, `NO_ACTIVE_PUBLICATION` (rollback). Reconciliation never throws for its own findings; it returns typed, classified findings (`MISSING_ACTIVE_POINTER`, `ORPHAN_ACTIVE_POINTER`, `POINTER_VERSION_MISMATCH`, `VERSION_MISMATCH`, `COUNT_MISMATCH`, `VECTOR_FORMAT_MISMATCH`, `<KEY>_MANIFEST_MISMATCH`, `INDEX_NOT_READY`, `AUTHORIZATION_CHECK_FAILED`, `EVALUATION_REGRESSION`, `SAMPLE_SEARCH_FAILED`, `CANDIDATE_EVIDENCE_MISMATCH`, `REQUIRED_DEPENDENCY_REVOKED`, `INSPECTION_FAILED`); a thrown inspector error is caught and reported as `INSPECTION_FAILED` / `retryable`.
