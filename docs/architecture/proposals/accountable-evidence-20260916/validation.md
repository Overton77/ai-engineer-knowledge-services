# Deliverable validation and limits

Status: **REFERENCE for the PROPOSED architecture.** [Entrypoint](README.md).

This is a research deliverable, not evidence that its proposed runtime exists. Validation is limited to document consistency, source inspection and links. No application tests, provider calls, database proofs, deployment, human labeling or benchmark runs were performed.

## Scope and ownership

- Authored files are confined to this new proposal directory. Existing working-tree modifications, generated documentation, production code, schema, migrations and configuration were not edited.
- The proposal is explicitly PROPOSED. It is not added to accepted architecture or generated navigation; registration can follow owner review without conflating research with settled policy.
- Shared schema remains owned by `ai-engineer-db-contract`. The recommendation reuses existing evidence, report, content, temporal and orchestration structures. It does not repurpose the design-document provenance schema or consolidate dashboards.
- Knowledge Services remains responsible for algorithms/admission/durable knowledge recovery; Mission Control remains responsible for cross-service dispatch and mission lifecycle. Research agents propose evidence and consumers use admitted contracts.

## Material uncertainties

No independent second reviewer was used; the task explicitly prohibited spawning additional agents. Human-gold accuracy, current deployed pins, source rights, vendor approvals, workload scale/cost and consumer rollout remain unverified. Several research sources were inspected only at abstract/metadata or selected-passage depth. Their use is limited accordingly.

Existing docs contain dated acceptance/pin statements and some report/recovery descriptions that lag inspected code. The baseline identifies those discrepancies rather than updating concurrent documents or inferring truth solely from timestamps. Further engineering design must freeze actual build/schema/method pins and review the source snapshot for drift.

The proposal's thresholds, budgets and corpus sizes are suggested acceptance criteria, not measurements. The exact operational contract for widespread correction, external exports, retention/deletion and independent-origin judgment needs product/owner decisions. Source completeness beyond the declared accessible frontier cannot be guaranteed.
