# Operator reconciliation HTTP service

EV-096, coordinator review, 2026-09-06. The configured API now exposes signed original-attempt settlement and authenticated applied-decision reads. Both use /v1/verification/extractions/:operationId/provider-attempts/:providerAttemptId/reconciliation (POST and GET). POST accepts only a registered full artifact handle and returns the compact applied accounting result with HTTP200. GET returns that same bounded result. Generated OpenAPI/JSON schemas and KnowledgeClient.applyProviderReconciliation/getProviderReconciliation match these routes.

The server-owned runtime requires explicit actor/provider/operator/key/basis grants plus original mission/deployment ownership. It snapshots caller inputs, rejects ungranted actors before database or Storage access, checks ownership before hydration, then constrains signature admission to that actor's configured issuer grants. POST additionally matches the admitted receipt's operation and provider attempt to the route before atomic application. GET uses the authenticated historical ledger read. Settlement/read ledger transactions explicitly select control_plane; ordinary worker authority is unchanged. The API requires operation.submit for POST and knowledge.read for GET, with the runtime's narrower grants required in both cases. No request header or body creates an operator grant.

Configuration: VERIFICATION_PROVIDER_RECONCILIATION_GRANTS_JSON is a bounded array of strict {tenantId,actor,providerId,keyId,operatorId,basis} records. Duplicate grant identities fail startup. VERIFICATION_PROVIDER_RECONCILIATION_PUBLIC_KEYS_JSON is an array of {keyId,publicKeyPem} trusted Ed25519 keys. The runtime also requires VERIFICATION_SERVICE_OWNERSHIP_GRANTS_JSON, the configured database and Supabase Storage credentials. An absent reconciliation grant configuration leaves the capability unavailable; partial configuration fails startup. Keep supplier_statement authority separate from synthetic_fixture authority. The service verifies registered decisions; it does not mint operator signatures or establish supplier billing truth.
