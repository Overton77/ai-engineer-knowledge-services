# Available environment variables

These keys are all available in `ai-engineer-knowledge-services/.env`:

- `UNSTRUCTURED_URL`
- `UNSTRUCTURED_API_KEY`
- `AI_GATEWAY_API_KEY`
- `POSTGRES_URL`
- `POSTGRES_URL_NON_POOLING`
- `SUPABASE_ANON_KEY`
- `SUPABASE_API_KEY`
- `SUPABASE_SECRET_KEY`
- `INTERFAZE_API_KEY`
- `TAVILY_API_KEY`
- `FIRECRAWL_API_KEY`
- `CURSOR_API_KEY`

Load them from that `.env`. Do not copy secret values into this workspace.
