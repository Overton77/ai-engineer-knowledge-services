## Verdict

**`not_ready`** (doc-only blockers; the code changes themselves are sound).

Two documented request examples that an agent is told to copy will be rejected by the running API (`VERIFICATION_CAPTURE_MODE_NOT_ADMITTED`; 403 "Verification operation ownership denied"), and the operator docs omit the ownership-grant shape and orchestration seeding that every verification mutation depends on. Everything else sampled (30 CLI rows, 30 MCP tools, 36 routes, all `VERIFICATION_*` names, `--wait` exit lattice, MCP tenant authorization) matches code; fixing A-01…A-06 is a documentation task of roughly a dozen edits.
