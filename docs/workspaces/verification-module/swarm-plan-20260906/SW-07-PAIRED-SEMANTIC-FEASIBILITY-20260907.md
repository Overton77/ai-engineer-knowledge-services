## Missing mutation coverage

`diagnostics-companies-v1/dataset.json` contains 20 adversarial mutations. It has algorithm, count/timeline, qualifier/safety, citation/publication/authority, population, workflow, conflict, and count-valued biomarker statements (for example `tru-biomarkers-mutated` and `gl-systems-mutated`). Those are count swaps, not biomarker-identity swaps. It has no `name`/company-name swap family, no institution/affiliation swap family, and no biomarker-identity/list swap family. Thus it cannot meet the specification's required names/algorithms/biomarkers/counts/institutions/qualifiers/citations monotonic-mutation coverage from `03-SWARM-INSTRUCTIONS.md` and VR-041. New name and institution pairs require a separately reviewed, immutable successor dataset/grant before any provider call; no existing v1 pair can stand in for them.

## Minimal implementation prerequisites

- A paired-run runner mode that takes two explicit v1 case IDs and verifies they are a distinct original/mutated `pairCluster`, each has exactly one authorized derived input, and both selector resolutions and digests match the frozen catalog.
- A bounded cph profile-grant artifact/configuration for Luna and Terra, scoped to the two created operation IDs, tenant, claims host, exact profile artifacts, and existing D-013 wire/token/budget limits. It must fail closed if the model discovery returns another model or either grant cannot be hydrated.
- A four-call reservation ceiling, serial execution, the existing cumulative-cost scan, and D-014's three-failure stop. Terra's reservation/price snapshot needs an explicit recorded basis; none appears in the v1 derived-input grant.
- A paired-report schema that labels Luna/Terra as same-provider comparison, keeps raw provider responses restricted, gives no human or independent-corroboration claim, and does not change admission.

These prerequisites are source/configuration work only. They are sufficient for a small genuine paired conformance execution under existing user authority, but not for the complete 40-case, cross-family, human-gold, or VR-041 acceptance claims.
