# Frozen Knowledge Services context fixture

Six explicitly selected real concepts copied before retrieval/documentation edits.
manifest.json pins exact SHA-256 bytes and observed Git HEAD. Working-copy bytes define
this fixture, not HEAD alone. Original evidence links remain; this fixture tests search,
not source execution or isolation proofs.

queries.json labels were fixed before ranking changes, authored by the agent from
observed business routes, without independent human adjudication. Eighteen positive
screening cases form a regression gate. Six positive and four negative heldout cases
are reported separately. These heldout results have now been observed; future tuning
needs new unseen cases. Failed cases remain in the report.

baseline-knowledge.mjs preserves the original parser/ranking with only the parser import
redirected to canonical vendor files. It is distributed only as a benchmark fixture; production search never imports it.

Original byte hashes remain in the manifest. Integrity checks use the additionally recorded
LF-normalized SHA-256 so portable copies and Git CRLF checkouts preserve the same frozen text.
