# Assertion and media decisions

An assertion declares what is claimed; a locator identifies source material. Mechanical
verification checks captured bytes, exact selectors and deterministic rules. It does not
establish semantic entailment or world truth. Keep mechanics, semantic support, source
authority, policy admission and sealing distinct. A seal is not admission.

## Media routing

The library supports twelve selectors: text quote, character position, JSON pointer,
multi-fragment text, HTML DOM, PDF text, bounding box, table, media timecode, repository,
dataset and API record. The last eight require canonical representations and admitted
source/projection lineage. They are not twelve acquisition tools.

Platform capture admits HTML DOM web-page representations and acquired PDF text + geometry
under server catalogs/grants. It does not thereby admit arbitrary image, audio or video
capture. Geometry selects existing tokens; timecodes select existing transcript segments.
Neither operation performs OCR, transcription or visual/audio understanding by itself.

The separate knowledge-verify executor accepts text quotes in claim/extraction intents.
It captures text/Markdown/JSON/HTML and converts supported documents through its parser.
It does not accept arbitrary native selector fields. Use the separately installed
knowledge-verify skill for that procedure; do not import internal algorithm packages.

## Representative agent scenario

An agent has two panel counts and must assert only Panel A's count. Require the source
capture and exact panel binding, not just matching digits. An ambiguous locator stays
unresolved until the admitted workflow supplies unique context. When the submitted
operation completes, read the authoritative claims result. Mechanical passed with policy
review is held; route it to recovery/adjudication. Do not invent an admitted result.

For a raw video, record the missing media path. A text transcript can be a separate source
but does not prove what appeared visually in a frame. For a PDF chart absent from the text
layer, preserve the unresolved visual residual rather than asserting a number from memory.

The executor's eleven field comparisons include exact, normalized text, decimal,
percentage, currency, unit, date, datetime, enum, identifier and checksum. Its 1.1.0 skill
documents explicit rule options and an offline CLI template. A matching executor build is
required; do not infer compatibility from an unchanged intent schemaVersion alone.

Report completeness measures declared assertions. It is not an independent search for
all omitted factual statements. Human-gold calibration, semantic quality optimization,
and complete arbitrary-media coverage remain outside the offline examples.
