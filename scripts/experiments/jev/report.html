Jev evaluates closed choices, ordered scores and hundreds of boolean questions. This lab tests it on public AI engineering resources through real worker processes and compares its decisions with an LLM.

What this run establishes

Confidence → LLM escalation

Fixed threshold 0.80, chosen before outcomes. High-confidence Jev decisions pass through; remaining rows use the actual GPT-4.1 mini result. This is a replayed cascade, not a production calibration.

Real process parallelism

Same 12 public documents, seven questions each. Serial submits await each response; parallel submits all 12 to the worker pool. Queueing and polling are included. One ordered trial, so speedup is descriptive.

Resource routing + retrieval shortlist

24 official README excerpts; source-purpose labels were curated before execution. Seven independent judgments share each document. Relevance ranks suitability for vector retrieval infrastructure.
